# Reusable investigation lessons

24 October 2026 IST. REA 6.7.0, skill 42; supported native cua access to Edge. Public documentation and source inspection have separate provenance.

1. Verify MCP and account access separately. A healthy REA connection does not expose an authenticated browser. Native Edge access worked despite the empty in-app browser inventory. No setup repair or native engine installation was necessary.
2. Select Edge by full application path when updater copies make its bundle ID ambiguous. Refresh UI state after user activity or stale element errors. Pasting a verified URL into the address bar was more reliable than one truncated typeText attempt.
3. The unified Music composer has Prompt and Lyrics anchors in one contenteditable area. Click the intended anchor before pasting and verify both regions. Marketplace and history initially retained separate drafts.
4. Set one variant and a fixed duration. The default was two variants and Auto duration. At 900 credits/minute, 90 seconds cost 1,350 and 150 seconds cost 2,250. A musical vocal style is not a personal speech clone.
5. Check history before retrying. The E05 client error followed a completed generation; refresh recovered the new version without another submission. One unchanged immediate tree also did not establish a failed E01 job.
6. The profile balance can be stale. Refresh Subscription to reconcile spending. Retain grouped debit boundaries when individual actions were not independently metered; a matched estimate sum is not a per-action receipt.
7. Expanded section plans are useful evidence, but they do not establish where planning executes or which API fields the website uses. Native UI notes are separate from REA Evidence. The exported REA bundle correctly has zero page-capture records.
8. Edit locality needs source and result files. Equal sample counts, zero estimated lag and retained-window correlations above 0.998 support E05 locality. The MP3s are not sample-identical; seams and musical improvement still require listening.
9. Unprompted ASR avoids supplying the expected lyrics to the measurement, but music can cause loops and false words. Preserve raw results and exclude unreliable spans. A better transcript is not better melody or diction. E13 has no demonstrated clarity win. Mixed-source pitch tracking also failed and was rejected as evidence.
10. Brief-only writing can produce a recurring hook and weak lines. Save and edit the actual generated words before selecting a winner. Do not spend on optional tests simply to use the allowance.
