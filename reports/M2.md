## Deviations and decisions to confirm

1. **Silence**: floor -50 dB, >= 0.5 s runs (as M0). Fraction >= 5 % is a WARNING in `checks_json` (status `warning`), failure only above 40 %. Both thresholds are settings (`silence_warn_fraction`, `silence_fail_fraction`).
2. **Failed take is kept, not replaced.** Takes are immutable, so a take that fails the technical checks stays as a row with `status: failed`; its automatic retry (new seed, same ordinal) is a new row with `retry_of`. Both audio files stay on disk. The frontend should show the failed one flagged, collapsed.
3. **Video queue "unknown"** (reachable but not a ComfyUI queue answer, timeout) makes the job wait with reason `video_queue_unknown` instead of running. Only connection-refused counts as idle (as PRD). I chose caution because the footprint is 51-55 GB.
4. **MPS gate** probes fresh before every real job (a few seconds via the ACE python), fails the job clearly if false; never CPU. The fake engine does not probe (`mps: null` in `/api/system`).
5. **Planner**: `Service.planner()` uses the other agent's `providers.registry.get_planner(settings)` (read only). It returns Basic unless `planner_provider` names a smart provider AND `planner_smart_enabled` is true; both default off and nothing in M2 sets them. `/api/system.planner_provider` reports the effective provider.
6. **Refine with nothing applicable** (e.g. free text under Basic) returns 422 `nothing_to_change` instead of spending a render on an unchanged plan.
7. **Replay status**: a duplicate idempotent POST returns 202 with `"replayed": true` (not 200), so clients need one code path.
8. **Graceful server stop** leaves a running job as `running` (engine terminated); the next boot re-queues it like a crash (counts as an attempt).
9. **Additional endpoints/columns** beyond section 10/7: `GET /api/takes/{id}`, `GET /api/exports/{id}/file`; columns `jobs.engine`, `jobs.cancel_requested`, `takes.engine`, `takes.native_sha256`, `takes.retry_of`, `takes.native_pruned_at`, `exports.engine`. Takes are immutable except pruning their native file.
10. **Exports**: MP3 is 320 kbps. The loudnorm step is two-pass with the measured values fed back; when linear gain would break the -1.5 dBTP ceiling (quiet-but-peaky music like T1) ffmpeg falls back to its dynamic mode, which lands on -16 +/- 0.1 LUFS in practice (measured -15.9). The loudness actually measured on the written file is stored; if a lossy encode overshoots -1.0 dBTP the export is redone once with one more dB of headroom.
11. **Security extras** not in the PRD: Host header must be 127.0.0.1/localhost, state-changing requests with a foreign `Origin` get 403 (blocks drive-by posts from other web pages to the local server).
12. `scripts/start.sh` uses `--timeout-graceful-shutdown 5` so open SSE streams cannot hang a stop.
