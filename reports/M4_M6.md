## Deviations and decisions

1. **`--bare` is OFF by default** (PRD says `--bare`). In this CLI version `--bare` never reads OAuth/keychain, so the subscription login would fail. It is a `bare` setting; without it `ANTHROPIC_API_KEY` is removed from the child env so the subscription is used. Unverified by execution: the exact JSON envelope of `claude -p --output-format json --json-schema`. The parser accepts `structured_output`, a `result` object or JSON text (fences tolerated); confirm with one real call when the user turns the provider on.
2. **Model schema is not the full `BriefCard`**: it is `LlmCardDraft` (no brief/provenance/provider/caption/lyric text); code fills those. Recipe choice is limited to r1-r3.
3. **`BriefCard.fallback` keeps its M1 meaning** ("nothing matched"). Provider fallback is reported by `PlanOutcome.fallback`/`fallback_reason`/`banner` (and `plan()` prepends the banner to `card.notes`). M1 files unchanged.
4. **Timeouts and HTTP errors are not retried** (only invalid JSON/invalid card, exactly once). Non-zero CLI exit and HTTP errors raise `PlannerUnavailable` and fall back.
5. **Free-text filter** on `feeling` (max 3 words), `avoid`, `flavour`: rejects instruction-like words (ignore, caption, prompt, "set the", brackets, URLs). Strict by design; a legitimate flavour phrase containing those words is dropped with a note.
6. **E3, E4, E5 requests cannot run on today's engine**: `run_takes.validate_request` accepts only `text2music` with null `src_audio`. Requests are generated and flagged `engine_ready: false`. E4/E5 arms: E4 is a single-arm question experiment (reference = original take); E5 pairs `cover` (control) with `cover + flow_edit_morph`. E2/E4/E5 use a yes/no question per arm; the 70%/10 rule is applied to the "yes" rate of the primary question. The sheet title is neutral (no tested parameter), since "shift 3.0 vs 1.0" would reveal the experiment.
7. **Observation on M1**: Basic's note text says "keyword rules, not an AI". The new badge/label/banner strings contain no "AI"; I did not change the M1 note.
8. `app/experiments/` has no `__init__.py` (not in my file list); it works as a namespace package when `app/` is on `sys.path` (`python -m experiments.x` from `app/`).
